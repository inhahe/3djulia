4D Julia Set Explorer

Explore 2D cross-sections and 3D hyperplane volumes of the 4-dimensional Julia set. Supports both complex z → z² + c and quaternion q → q² + c iteration.

Navigation

←→ Move left / right  (along screen-x)
↑↓ Move up / down  (along screen-y)
WS Move in / out  (3rd axis)
QE Move ± in remaining dimension
+− / scroll   Zoom in / out
Mouse drag   Pan (2D) • Orbit (3D)

4D Rotation

1–6 Select rotation plane
<> Rotate in selected plane

Display

Tab Toggle 2D / 3D mode
F Toggle fractal type (Complex / Quaternion)
C Cycle color palette
IK More / fewer iterations
P Cycle 3D quality preset
R Reset view
H Toggle this help

Tip: The Mandelbrot set is the c-plane cross-section at z₀ = 0. Rotate in the X–R or Y–I planes to smoothly blend between Julia and Mandelbrot views.
