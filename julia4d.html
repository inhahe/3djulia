4D Julia Set Explorer

Explore 2D cross-sections and 3D hyperplane volumes of the 4-dimensional Julia set z → z² + c, where (x, y) = z₀ and (r, i) = c.

Tip: The Mandelbrot set is the c-plane cross-section at z₀ = 0. Rotate in the X–R or Y–I planes to smoothly blend between Julia and Mandelbrot views.
